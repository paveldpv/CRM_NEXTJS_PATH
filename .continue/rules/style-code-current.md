## Стиль кода

1. Анализируй существующий код в проекте и **подражай моему стилю**
2. Используй понятные имена переменных и функций
3. Добавляй JSDoc комментарии к сложным функциям
4. Используй `async/await`, избегай `.then()`

## Что делать при сомнениях

- Если задача неясна — **спроси**
- Если видишь потенциальную ошибку — **предупреди**
- Если код можно улучшить — **предложи** улучшение

## Запрещено

- ❌ Использовать MUI (Material UI)
- ❌ Предлагать новые библиотеки без моего разрешения
- ❌ Писать код для неизвестных сущностей
- ❌ Игнорировать существующий стиль кода
- ❌ Фантазировать — если не знаешь, спроси
